# Security policy

Telestra is an early-stage project. Security reports are welcome, especially for issues involving account sessions, local message data, downloaded files, credentials, logging and network communication.

## Reporting a vulnerability

Please do not publish exploitable vulnerabilities, private account data, authentication codes, tokens or session files in public issues.

If GitHub private vulnerability reporting is enabled for this repository, use the **Security** tab to submit a private report. Otherwise, contact the repository maintainer through a private GitHub channel and ask for a secure reporting method before sending sensitive details.

Include the affected commit or version, impact, reproduction steps and any relevant sanitized logs. Please allow time for investigation and a fix before public disclosure.

## Scope

The policy covers Telestra code and its packaging/configuration. Vulnerabilities in Telegram, TDLib, GTK, libadwaita, Linux distributions or other dependencies should be reported to their respective maintainers as well.
